# 接线说明（第一版：灯）

> 市电危险。过滤泵继电器部分未启用前，不要接 220V。

## 电源拓扑

```text
220V 墙插
  └─ 12V/24V 电源砖（藏柜内）
        ├─ +  → 灯条正极（V+ / +）
        ├─ -  → 灯条电源地、MOSFET 电源地、ESP32 GND（共地）
        └─ （勿把灯条电流接到 ESP32 的 5V/3V3）
```

ESP32 可用 USB 供电（调试），或用合适的 5V 降压从同一低压侧取电。  
**灯条大电流只走电源砖和 MOSFET，不走 ESP。**

## 灯条 + MOSFET（单色调光）

常见「共阳」灯条（正极常接电源正，负极由 N‑MOS 拉低调光）：

| 连接 | 接到 |
|------|------|
| 灯条 + | 电源砖 + |
| 灯条 − | MOSFET 输出（灯负载端） |
| MOSFET 电源 + / VIN | 电源砖 +（若模块需要） |
| MOSFET GND | 电源砖 −，并与 ESP32 GND 相连 |
| MOSFET SIG / PWM | ESP32 **GPIO16**（与 `aquarium.yaml` 一致） |

请使用 **3.3V 逻辑电平** MOSFET 模块。便宜的 IRF520 模块在 3.3V 下可能不完全导通。

## 引脚一览（与 YAML 对应）

| 功能 | GPIO | 说明 |
|------|------|------|
| 灯 PWM | 16 | MOSFET SIG |
| 泵继电器 | 17 | 默认注释，未接线 |
| 喂食舵机 | 18 | 默认注释，未接线 |
| 状态 LED | LED_BUILTIN | 板载（若有） |

不同开发板丝印可能不同；以你板子的 GPIO 编号为准，改 YAML 即可。

## Home Assistant

烧录成功并联网后，HA → 设置 → 设备与服务 → 应出现 ESPHome 设备。  
添加后应有灯光实体（如 `light.tank_light`），可开关与调亮度。

## 下一步（泵 / 喂食）

- **泵**：GPIO17 → 继电器模块 IN；继电器切过滤泵的 **火线**；共地与隔离按模块说明。
- **喂食**：GPIO18 → 舵机信号线；舵机另供 5V，地与 ESP 共地。
