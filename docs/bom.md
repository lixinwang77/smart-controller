## 电压怎么选

- **24V**：同功率电流更小，1 m 灯条压降更小，推荐。
- **12V**：模块更多、MOSFET 示例多；60 cm 也完全够用。
- **灯条电压必须 = 电源电压**；ESP32 与 MOSFET 信号侧共地，灯电流不进 ESP。

## 下单核对清单

- [ ] 灯条电压写清（12 或 24）
- [ ] 电源电压一致，功率留余量
- [ ] 铝槽宽度对得上灯条
- [ ] MOSFET 标注支持 3.3V 逻辑
- [ ] ESP32 能用电脑 USB 识别（买带回环/能传数据的线）
