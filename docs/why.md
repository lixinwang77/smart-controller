# 为什么做 Smart Controller

可以用一堆远程开关 / 智能插座分别控灯、泵、喂食，功能上也能「远程」。

**不做那条路，是因为目标不是「每个设备都能远程」，而是「所有控制落在同一个系统里」。**

## 远程开关拼凑的问题

- 灯一个 App / 一个实体，泵一个插座，喂食又一个品牌
- 定时、场景各写各的，出差要开好几个入口
- 想做联动（例如开灯时确认泵在转）很别扭
- 以后加传感器、自动化，生态越加越碎

## 这套方案要解决的

用 **Home Assistant + ESP32（ESPHome）** 把鱼缸相关能力收成一个控制台：

- 灯、泵、喂食（以及以后的水温、漏水等）都是同一套里的实体
- 共用同一套时间表、自动化和手机入口
- 扩展是往同一个系统里加模块，而不是再买第三个封闭生态

## 一句话

不是为了证明「开关必须自己做」，而是为了 **统一操作面**——远程开关解决不了，本项目就是为这个而建。
